# General Coding Workflow

General Coding 用于已知 domain workflow 之外的普通 coding 任务。

V0 只定义未来 assessment 维度：

- Complexity。
- Uncertainty。
- Risk。
- Testability。

未来 Dynamic Workflow Composer 可以选择：

- 澄清深度。
- Specification 深度。
- TDD 深度。
- Context strategy。
- Subagent strategy。
- Review 和 verification 深度。

V0 暂不实现 General Coding 的完整 workflow。
