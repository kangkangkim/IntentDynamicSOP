IDC Discovery-First Routing Overview

不同用户输入先进入 Discovery。Discovery 内部完成 intake、normalize、maturity detection，然后再按触发条件分流到澄清、对齐、领域路由和执行闭环。

Input Triggers

  • Raw Idea -> Discovery -> Brainstorming if alternatives are needed.
  • Structured Request -> Discovery -> Grill Me if critical fields are missing.
  • TR3 -> Discovery -> route directly when behavior is identifiable.
  • Approved Pack / Resume -> Discovery -> automated closure resume.

Routing Triggers

  • D3A signals -> D3A Domain Module.
  • Registered team-domain signals -> that team's Domain Module.
  • No fixed domain but dynamic orchestration needed -> Dynamic Scenario.
  • Simple ordinary coding -> General Coding Fallback.

Execution Triggers

  • Execution never starts before Alignment approval.
  • GC / original repo ability needed -> Skill Adapter Router.
  • DT build / tran_build -> team adapter binding required.
  • DONE -> only after evidence gate passes.
