Raw Idea

一句话、早期想法、还不知道要做成什么。

Discovery normalized_request
  • input_type: raw_idea
  • maturity_signal: vague
  • draft intent seed
  • known unknowns preserved
Human Alignment Gate Detects: idea not alignment-ready
  • goal is unstable
  • solution direction missing
  • acceptance cannot be checked
  • Domain / Lane would be guesswork
Trigger: needs alternatives -> Brainstorming
Brainstorming View 先发散，不要 approval
  • 公司已有 Brainstorming -> Team Binding
  • 否则 shared fallback
  • 输出 2-3 approaches / trade-offs / recommended direction
Next check: direction chosen but contract gap -> Grill Me
Pending Hold Domain / Lane

Human Alignment Gate 判定 raw idea 没有稳定 contract 前，不做 D3A / General / Team Domain 最终判断。

Blocked No execution

不调用 coding、DT、GC、build adapter。

Draft only Output

Brainstorming View 或 Clarification View。

Structured Request

目标和行为基本清楚，但可能缺验收、边界或风险。

Discovery structured_requirement
  • goal present
  • behavior present
  • acceptance maybe partial
  • risk / boundary signal extracted
Human Alignment Gate Detects: critical gap or approval-ready
  • contract gap
  • scope gap
  • completion gate gap
  • API semantics / file placement gap
If gap: Grill Me. If clean: Alignment View.
Clarification View 选择题问题卡
  • 每轮最多 5 个 frontier questions
  • 答案回写 normalized_request / contracts
  • 再次进入 Human Alignment Check
Scenario Router Trigger: Human Alignment ready
  • Dynamic Scenario
  • Domain Module
  • General fallback
General / Domain Execution Trigger: user approved
  • bounded execution unit
  • required contracts exist
Completion / Escalation Evidence required

测试、检查或 blocker 摘要。

TR3 Design Doc

已有设计文档、DT 线索、影响范围或验收标准。

Discovery tr3_design_doc
  • extract API / behavior
  • extract DT design hints
  • extract lane signals
  • extract evidence candidates
Human Alignment Gate Detects: TR3 sufficient or incomplete
  • behavior/API semantics clear?
  • DT ambiguity exists?
  • required evidence named?
  • repo facts conflict with doc?
If incomplete: Grill Me / Grill With Docs. If sufficient: Alignment View.
Alignment View TR3 summary
  • change type / change shape
  • Domain / Lane candidates
  • required contracts
  • evidence plan
D3A / Team Domain Trigger: D3A domain signals
  • Domain Module Router
  • Lane Resolver
  • Contract Gate
  • D3A fixed user-designed workflow
D3A Coding / DT Adapters Trigger: approved fixed D3A workflow
  • fixed layer registry only
  • DT design / writer if needed
  • DT RED / GREEN
  • tran_build
D3A Completion Gate All evidence PASS

Required DT GREEN + tran_build PASS。

Approved Pack / Resume

用户已 approve，或从 runtime checkpoint 恢复。

Discovery approved_or_resume
  • approval ref signal
  • load runtime_state
  • resume checkpoint
Human Alignment Gate Detects: valid approval or stale state
  • validate approval ref
  • contract still current?
  • checkpoint trustworthy?
  • scope changed since approval?
If stale: Escalation / re-alignment. If valid: resume.
No new Human View 默认不再追问

Human Alignment Gate 只在 blocker / missing binding / stale contract / scope drift 时回人。

Automated Closure Trigger: valid checkpoint
  • execution unit planner
  • delegation router
  • knowledge gate
Continue execution Trigger: tool evidence boundary
  • rerun verification if needed
  • targeted fix on failure
Completion / Escalation Resume-safe output

只展示 summary / refs / next action。

Discovery Owns

  • intake / normalize
  • preserve input type
  • maturity signal, not readiness decision
  • draft intent seed
  • facts and unknowns extraction

Human Alignment Owns

  • alignment readiness detection
  • critical gap detection
  • provider trigger decision
  • approval / stale approval gate
  • blocks execution before user approved

Routing Owns

  • Scenario Router
  • Domain Module Router
  • Lane Resolver
  • Contract Gate

Execution Owns

  • General Coding / D3A Coding / Team Domain
  • Skill Adapter Router
  • Team Binding for confidential commands
  • Evidence Gate before DONE
