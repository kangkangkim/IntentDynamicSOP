Input-Specific Triggers

  • Raw Idea -> Discovery, then Brainstorming if alternatives are needed.
  • Structured Request -> Grill Me only if critical contract fields are missing.
  • TR3 -> skip Discovery unless behavior cannot be identified.
  • Approved Pack / Resume -> skip pre-alignment and enter automated closure.

Routing Triggers

  • D3A signals -> D3A Domain Module.
  • Registered team-domain signals -> that team's Domain Module.
  • No fixed domain but dynamic orchestration needed -> Dynamic Scenario.
  • Simple ordinary coding -> General Coding Fallback.

Execution Triggers

  • GC / original repo ability needed -> Skill Adapter Router.
  • Company Brainstorming -> Team Binding.
  • DT build / tran_build -> team adapter binding required.
  • DONE -> only after evidence gate passes.
