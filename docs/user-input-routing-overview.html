Approved Pack / Resume

用户已 approve，或从 runtime checkpoint 恢复。

Discovery approved_or_resume
  • validate approval ref
  • load runtime_state
  • resume checkpoint
Skip pre-alignment Trigger: approval exists

除非 contract 已失效或 checkpoint 不可信。

No new Human View 默认不再追问
