从用户输入开始，所有前置能力按从左到右的成熟度推进；每条线都以明确触发条件进入下一步。

Skip Rules

  • Short but structured input skips Brainstorming.
  • TR3 skips Discovery unless too incomplete to identify behavior.
  • Approved Alignment Pack resumes at automated closure.
  • Execution adapters never run before user approval.

Provider Choice

  • Company Brainstorming triggers through Team Binding.
  • Shared Brainstorming fallback keeps the same draft spec shape.
  • Grill Me is built into this project.
  • Grill With Docs runs only when docs should be updated.

Execution Entry

  • Alignment must be approved.
  • Domain and Lane must be selected.
  • Required contracts must exist.
  • Completion must use tool evidence, not confidence.
Core rule

不成熟输入只触发 Discovery、Brainstorming、Grill Me 或 Grill With Docs；只有 Alignment 被用户 approve 后，才进入 General / D3A / GC / DT / build 执行。
