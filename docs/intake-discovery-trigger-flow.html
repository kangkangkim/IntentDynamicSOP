Detection Rules

  • Human Alignment Check detects whether input is approval-ready.
  • Raw idea triggers Brainstorming when alternatives are still needed.
  • Structured input triggers Grill Me only when critical gaps remain.
  • Approved Pack / Resume bypasses new questions only after approval ref is validated.

Provider Choice

  • Company Brainstorming triggers through Team Binding.
  • Grill Me is built into this project.
  • Grill With Docs runs only when docs should be updated.
  • Provider choice is a Human Alignment Gate decision, not a Discovery decision.

Execution Entry

  • Execution is not part of Discovery.
  • user approved is required before Execution.
  • Human Alignment must be approved first.
  • Stale approval returns to Escalation / Re-alignment.
  • Completion must use tool evidence, not confidence.
Core rule

Discovery 先把输入变成可判断的 draft intent；Human Alignment Check 统一检测成熟度、关键缺口、文档需要和 approval 有效性。只有关键缺口关闭并完成 Human Alignment approval 后，才进入 General / D3A / GC / DT / build 执行。
