1 IDC Harness 的设计原则

先理解框架，再设计团队流程

IDC Harness 不替团队规定唯一 SOP。它稳定核心 Gate，把可变化的策略交给团队配置。

Intent first先根据输入成熟度完成 Human Alignment，再进入 Domain 和实现；Domain 不能绕过用户批准。
Domain owns the execution modelGeneral 使用动态 Lane，D3A 使用固定范式，Custom 由团队声明 fixed、dynamic 或不使用 Lane。
Skills are capabilities注册 Skill 只代表能力可用；是否执行、执行顺序和触发条件由 Domain、Lane 与编排策略决定。
Knowledge follows execution知识不一次性灌入上下文。D3A 按 Layer、General 按 Lane、Custom 按团队执行单元渐进加载。
Evidence closes the loop代码完成不等于流程完成；只有验证证据和 Completion Gate 均通过后才进入 DONE。
One team-owned entry团队只维护 team-config.yaml；Harness Core、企业 Skills 和知识正文各自保持独立。

团队主要面对哪类开发任务？

可以多选。这描述团队具备哪些开发能力；每次任务仍由 Scenario Router 只选择一个最匹配的 Domain。

4 根据 Domain 设计执行模型

D3A 使用 Harness 固定范式

选择 D3A 后不再判断 fast、lite、complex。Planner 按 DT 准备知识，拆分到固定 Layer，再通过 TDD、DT build 与 tran build 完成闭环。

Fixed workflow · 不使用 LanePlanner → DT knowledge → Layer execution units → TDD → DT GREEN → tran build PASS → Completion Gate

这个范式如何被识别和执行？

三个 Skill 分别拥有主流程、规划和完成判断；Core 仍然拥有 Router、Human Alignment 与 Evidence Gate。

General 根据任务风险动态选择 Lane

General 的执行模型由 Harness 固定为 dynamic。下一步再决定每条 Lane 可以使用哪些 Skills，以及采用 autonomous 还是 ordered。

Dynamic workflow · fast / lite / complexLane Resolver 依据范围、风险、测试需求与架构影响选择 Lane；团队配置每条 Lane 的能力边界和顺序。
2 Human Alignment 策略

不同成熟度的输入，会走不同的 Alignment 路径

Input Adapter 先判断成熟度，再按运行时 signal 选择最小必要步骤。下列策略由 IDC Core 保证，Domain 和团队配置都不能绕过最终批准门。

Raw idea只有目标或愿望，行为和验收仍模糊
Discovery → Brainstorming（需要方案时）→ Grilling（仍有关键缺口时）→ Alignment Checkraw_idea 必须触发 Discovery；不能因为指定了 General 或 D3A 就跳过。
Structured requirement已有目标、核心行为和部分验收线索
跳过 Discovery / Brainstorming → Grilling（存在关键缺口时）→ Alignment Check短需求不等于 raw idea；结构已经足够时不做无意义发散。
TR3 design doc已有设计、DT、验收或影响范围
TR3 Adapter → Grilling（critical_gaps_remain）→ Grill With Docs（docs_clarification_required）→ Alignment Check默认按缺口触发；团队可加入 tr3_design_doc signal，让 TR3 强制经过某一步。
Approved alignment已有仍然有效的 approval 或 checkpoint
校验 approval validity → 继续执行；发现 scope drift → 重新 Alignment恢复任务时先验证原批准是否仍覆盖当前事实。

使用默认 Alignment，还是设计团队自己的对齐流程？

默认策略按运行时 signal 选择最小必要步骤。团队流程可以调整每一步的 Skill、顺序和触发 signals，也可以插入新的对齐步骤。
