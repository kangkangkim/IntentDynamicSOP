main 不复制全部工作上下文；它持有决策链、批准结果、packet 摘要和 evidence refs。

4. Contract 冻结

Main 持有 Alignment Pack 摘要，等待用户批准。

Session 占用对比

main agent 是编排与记账上下文；subagent 是短生命周期工作上下文。

Main Agent Session保留

  • 用户原始输入和最新指令。
  • 输入成熟度、Domain、Lane、Contract Gate 决策。
  • Human Alignment 的批准状态。
  • Execution Unit 列表和当前闭环状态。
  • Subagent 返回的 summary、changed paths、evidence refs。

Subagent Session隔离

  • 只接收当前 execution unit 或当前 D3A Layer Context Packet。
  • 可以读取局部文件、相关测试和局部 provider finding。
  • 内部推理、长日志、完整搜索结果不回灌 main。
  • 完成后返回最小可审计结果：summary + evidence_ref。
  • 失败时只扩大责任 unit 的上下文。

关键规则

这三条决定上下文不会在运行中失控。
先对齐，后自动

Brainstorming、Grill Me、Alignment 都在 main session 完成；用户批准后才展开 subagent 执行。

分 packet，不全文

OKL、grep、CodeGraph 进入 Context Packet 的是 summary / refs / keywords，不是全文或长日志。

subagent 不污染 main

subagent session 是临时工作区。main 只吸收可审计摘要和工具 evidence，不吸收完整工作上下文。
